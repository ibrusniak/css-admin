# CSS Admin

> Также доступно на: [English](README.md) | [Українська](README.uk.md)

Android-приложение для администрирования серверов **Counter-Strike: Source** через протокол **RCON** (Remote Console).

## О проекте

CSS Admin позволяет управлять сервером CS:S прямо с телефона, без запуска игрового клиента. Приложение работает по тому же протоколу Source Engine RCON, что используется внутриигровой консолью.

## Возможности

- 📊 Просмотр статуса сервера и списка подключённых игроков
- 🤖 Добавление / кик ботов (за террористов или контр-террористов)
- 🔁 Перезапуск текущего раунда
- 🗺️ Интерактивный диалог выбора карты (поддержка больших списков через многопакетный RCON)
- 👢 Удобное управление игроками (выбор и кик игрока по ID из отсортированного списка)
- 💻 Отправка произвольной RCON-команды и просмотр ответа сервера
- 🕒 История команд с автодополнением для быстрого повторного ввода
- ⚙️ Адрес сервера, порт и пароль RCON настраиваются на устройстве (экран настроек)

## Требования

- Android 10 (API 29) или выше
- Работающий сервер CS:S с включённым доступом по RCON

## Настройка

1. Установите приложение
2. Откройте **Настройки** и введите IP сервера, порт и пароль RCON
3. Используйте кнопки на панели инструментов или поле ввода команды для управления сервером
