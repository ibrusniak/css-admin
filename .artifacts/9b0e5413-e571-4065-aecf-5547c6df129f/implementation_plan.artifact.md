# Исправление бага с историей команд в AutoCompleteTextView

Пользователь сообщил о баге: после выбора команды из истории и её выполнения, список истории перестает появляться.

## Исследование и корень проблемы

В ходе анализа кода `MainActivity.kt` обнаружены следующие проблемы:

1.  **Удаление данных из адаптера**: В методе `addToHistory` вызывается `commandHistoryAdapter.clear()`. Так как адаптер инициализирован списком `commandHistory`, метод `clear()` очищает сам этот список. Последующий вызов `addAll(commandHistory)` ничего не добавляет, так как список уже пуст. В итоге адаптер становится пустым, и выпадающий список больше не показывается.
2.  **Отсутствие обновления адаптера в `onStart`**: Метод `loadCommandHistory` обновляет список `commandHistory`, но не уведомляет адаптер об изменениях.
3.  **Непоследовательность в обработке команд**: При нажатии кнопки "Send" команда добавляется в историю и поле очищается. При отправке с клавиатуры (IME Send) команда выполняется, но не добавляется в историю и поле не очищается.
4.  **Фильтрация AutoCompleteTextView**: После выбора элемента из списка `AutoCompleteTextView` применяет фильтр. При последующем открытии списка (особенно если текст был очищен) фильтр может мешать отображению всех элементов.

## План верификации

### Ручная проверка
1. Открыть приложение, ввести команду "status", нажать Send.
2. Проверить, что при клике на поле появляется история с одной командой.
3. Ввести "bot_kick", нажать Send.
4. Проверить, что в истории две команды.
5. Выбрать "status" из истории, нажать Send.
6. **Критическая проверка**: Снова кликнуть на поле ввода. Список истории должен появиться и содержать "status" на первом месте (так как это была последняя выполненная команда).
7. Проверить отправку через Enter на клавиатуре.
