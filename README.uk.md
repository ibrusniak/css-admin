# CSS Admin

> Також доступно: [English](README.md) | [Русский](README.ru.md)

Android-застосунок для адміністрування серверів **Counter-Strike: Source** через протокол **RCON** (Remote Console).

## Про проєкт

CSS Admin дозволяє керувати сервером CS:S прямо з телефону, без запуску ігрового клієнта. Застосунок працює за тим самим протоколом Source Engine RCON, що використовується внутрішньоігровою консоллю.

## Можливості

- 📊 Перегляд статусу сервера та списку підключених гравців
- 🤖 Додавання / кік ботів (за терористів чи контр-терористів)
- 🔁 Перезапуск поточного раунду
- 💻 Надсилання довільної RCON-команди та перегляд відповіді сервера
- 📜 Прокручуваний лог команд із кольоровою індикацією (команда / успіх / помилка)
- ⚙️ Адреса сервера, порт і пароль RCON налаштовуються на пристрої (екран налаштувань) — ніколи не зберігаються в коді та не потрапляють у репозиторій

## Вимоги

- Android 10 (API 29) або вище
- Робочий сервер CS:S із увімкненим доступом через RCON

## Налаштування

1. Встановіть застосунок
2. Відкрийте **Налаштування** та вкажіть IP сервера, порт і пароль RCON
3. Використовуйте кнопки на панелі інструментів або поле вводу команди для керування сервером

## Технології

- Kotlin
- Android SDK (AppCompat, Material Components, ConstraintLayout)
- Kotlin Coroutines
- Прямі TCP-сокети з реалізацією протоколу Source RCON
